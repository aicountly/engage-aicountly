# Scheduled jobs of Engage (E8-OPS, F160). Installed into the deploy user's crontab by the production deploy
# (.github/workflows/deploy-production.yml -> bin/ops/post-deploy-jobs.sh -> bin/ops/install-jobs.sh --apply); check on
# the server with `bash bin/ops/install-jobs.sh --check`. `php spark engage:console-audit-deliver` reports itself to
# Console's Cron Job Monitor (engage.console_audit_deliver; app/Libraries/CronHeartbeat.php, key
# CONSOLE_CRON_MONITOR_KEY in api/.env, written by the deploy from the repo secret), so it runs WITHOUT the run-job.php
# wrapper — wrapping it with --monitor would report every run twice.
# The seller-programme crons (docs/SELLER_PROGRAM.md § 11) are not listed here yet: they stay hand-installed, and a
# hand-installed line for them is left alone.
#! app: engage
# CodeIgniter on its Postgre driver: the PHP CLI needs pgsql (not pdo_pgsql).
#! php-ext: pgsql
# Replaces the hand-installed line README.md used to give, so the job never runs twice. The spark command name is
# Engage's own.
#! legacy-pattern: spark[[:space:]]+engage:console-audit-deliver
# docs/LICENSING.md used to tell operators to hand-install the hourly expiry line; this block replaces it.
#! legacy-pattern: spark[[:space:]]+engage:licences-expire
# name                  | schedule    | command (run from the api folder)
console-audit-deliver   | */5 * * * * | {php} spark engage:console-audit-deliver
# Licensing (docs/LICENSING.md §6-§8): expiry hourly (a paid plan that ends falls back to Basic; never restricts),
# the Engage -> Manage entitlement push every minute (dormant and exit 0 until MANAGE_API_BASE_URL /
# ENGAGE_OUTBOUND_MANAGE_* are set) and the report-only drift check daily. Each reports itself to Console's Cron Job
# Monitor (engage.licences_expire, engage.entitlements_push, engage.entitlements_reconcile).
licences-expire         | 23 * * * *  | {php} spark engage:licences-expire
entitlements-push       | * * * * *   | {php} spark engage:entitlements-push
entitlements-reconcile  | 41 4 * * *  | {php} spark engage:entitlements-reconcile
